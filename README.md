# Hardware Concept

Suggested prototype components:

- ESP32 or Arduino
- Camera / ESP32-CAM
- DC geared motors
- Motor driver
- Conveyor belt or floating net
- Plastic collection bin
- Ultrasonic/water-level sensor
- Battery pack
- Optional GPS module
- Optional solar charging unit

## Basic Connections

Camera/Sensors -> ESP32/Controller -> Motor Driver -> Collector Motor

The actual circuit should be adapted to the selected components and tested
on a small controlled water tank before field deployment.
